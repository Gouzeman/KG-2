# KG-2 — трёхмерная визуализация

Программа строит трёхмерную фигуру методом тиражирования пятиугольного сечения вдоль ломаной траектории. Угол поворота каждого сечения считывается из файла `model.txt`.

Модель находится внутри нейтральной комнаты. Стены, пол и потолок участвуют в расчёте освещения. По умолчанию используется узконаправленный прожектор около потолка.

## Запуск

1. Открыть `KG-2.sln` в Visual Studio 2022.
2. При необходимости восстановить пакет NuGet `freeglut.3.2.2.v140`.
3. Выбрать конфигурацию `Debug` или `Release` и платформу `x64`.
4. Собрать и запустить проект.

## Формат model.txt

```text
количество_вершин_сечения
x_1 y_1
...
x_n y_n
количество_точек_траектории
x_1 y_1 z_1 угол_поворота_1
...
x_m y_m z_m угол_поворота_m
```

Вершины выпуклого сечения перечисляются по контуру. Углы задаются в градусах.

| Текстура шлифованного металла | `6` |

| Сглаженные/плоские нормали | `S` |
| Включить освещение | `L` |
| Удалённый направленный источник | `1` |
| Точечный источник | `2` |
| Прожектор | `3` |
